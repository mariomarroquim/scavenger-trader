# Scavenger Trader

Automate a Crypto scalping trading strategy that targets consistent, small gains on [Binance](https://www.binance.com) via its REST API. The current implementation was generated by [Gemini 1.5 Pro](https://gemini.google.com/app). It leverages a [Fibonacci retracement level](https://www.investopedia.com/terms/f/fibonacciretracement.asp) to trade [ETH/BRL](https://www.binance.com/pt-BR/trade/ETH_BRL?type=spot), and has been tested in production with real funds.

## Instructions

1. Add Fiat funds to your Binance account.
2. Edit and copy the specs from [scavenger_trader.md](https://github.com/mariomarroquim/scavenger-trader/blob/main/scavenger_trader.md) into an LLM to generate [scavenger_trader.rb](https://github.com/mariomarroquim/scavenger-trader/blob/main/scavenger_trader.rb).
3. Set the `BINANCE_API_KEY` and `BINANCE_API_SECRET` environment variables.
4. Run `./run.sh` to start trading.
