# Scavenger Trader

Automate a Crypto scalping trading strategy that targets consistent, small gains on [Binance](https://www.binance.com) via its REST API. The current implementation was generated by [Claude Opus 5.5](https://claude.ai) on October 26, 2026. It trades [ETH/BRL](https://www.binance.com/pt-BR/trade/ETH_BRL?type=spot), and has been tested in production with real funds.

## Strategy

1. Place a limit buy order with the available fiat balance at the current average price minus 0.075%, and wait for it to fill.
2. Place a limit sell order with the available crypto balance at the buy's average price plus 0.225%.
3. If the sell is still unfilled after an hour, reprice it to the buy's average price plus 0.150%.
4. If it is still unfilled after another hour, market sell the whole available crypto balance.
5. Repeat the cycle indefinitely, skipping it while there are no available funds.

## Instructions

1. Add Fiat funds to your Binance account.
2. Edit and copy the specs from [scavenger_trader.md](https://github.com/mariomarroquim/scavenger-trader/blob/main/scavenger_trader.md) into an LLM to generate [scavenger_trader.rb](https://github.com/mariomarroquim/scavenger-trader/blob/main/scavenger_trader.rb).
3. Set the `BINANCE_API_KEY` and `BINANCE_API_SECRET` environment variables.
4. Run `./start.sh` to start trading, and `./stop.sh` to stop.
