# Scavenger Trader

Scavenger Trader is a set of Ruby scripts that trade [ETH/BRL](https://www.binance.com/pt-BR/trade/ETH_BRL?type=spot) using different strategies. Each script is generated from a Markdown spec (e.g.,`scavenger_trader.md` → `scavenger_trader.rb`), and the spec is the source of truth for its behavior.

## Instructions

1. Add Fiat funds to your Binance account.
2. Set the `BINANCE_API_KEY` and `BINANCE_API_SECRET` environment variables.
3. Run the script you want (e.g., `ruby scavenger_trader.rb`).
